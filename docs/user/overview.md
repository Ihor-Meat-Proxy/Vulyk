# Overview

Vulyk is a self-hosted test management system for manual and automated testing. Use this help to learn the product flows available in your instance.

## What you can do

- Organise **projects**, **folders**, and **test cases** with keys, tags, and custom fields
- Link **requirements** and track coverage
- Plan **runs**, record **executions**, and review **reports**
- Connect **CI** reporters and automation Git repositories
- Use optional **AI** assist for case generation and chat (when configured)
- Administer users, appearance, languages, backups, and updates

## First-time setup

If this is a new install, complete the setup wizard (or CLI/Compose seed) to create the first admin, then sign in. Operators: see the install and first-run guides shipped with your deployment.
